# All we hear is CoPilot, but how to make it (Data) secure?

**Speaker(s):** Tim Hermie — session on the [European MCT Summit 2024, Rijswijk](https://european-mct-summit-2024.sessionize.com/) agenda.

## Abstract

Copilot unlocks a lot of data and insights for your users. But without the proper setup of Data Security, it's risky that Copilot will get too much critical information and as an organization you don't want that happening. In this session we'll show you what to implement (Labeling - DLP - ...) to have a good ethical working Copilot and where your data is secure in the organization.
