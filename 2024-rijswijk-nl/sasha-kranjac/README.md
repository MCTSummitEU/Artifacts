# Sasha Kranjac

Sasha is a Security and Azure person, Cloud Security Architect, and Instructor. He began programming in Assembler, met Windows 3.0 and Windows NT 3.5, and was hooked to IT ever since. 

He owns IT Training and Consulting companies that empower individuals and organisations worldwide to learn, be effective and stay secure in the Cloud. 

Aside from Cloud/Security Architecture and consulting, he delivers Microsoft, CompTIA, EC-Council and own bespoke Azure and Security courses and PowerClass Workshops internationally. 

Sasha is a Microsoft Regional Director, Microsoft Security MVP and Microsoft Azure MVP, MCT, MCT Regional Lead, Certified EC-Council Instructor (CEI), frequent speaker at various international conferences, events and user groups, book author on cloud security, Microsoft Azure, and Windows Server.
