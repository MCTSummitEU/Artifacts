# Using ChatGPT and other generative AI tools in education

**Speaker(s):** Patrick Kersten, Sjon Post — session on the [European MCT Summit 2024, Rijswijk](https://european-mct-summit-2024.sessionize.com/) agenda.

## Abstract

ChatGPT and other generative AI tools have become an indispensable part of our society.

These tools already play an important role in education and they will only become more popular. Not only as subjects in a training course, but mainly as tools that we can use in our education. Make sure you don't miss out on this!

Would you like to know more about the various AI tools such as ChatGPT, MidJourney, Google Bard and Microsoft Copilot, and are you curious about practical examples of how you can use them in a business environment or as a technical trainer of teacher? Then don’t miss out on this session!
