# Calling all admins: Teams Telephony deep-dive

**Speaker(s):** Ralph Eckhard — session on the [European MCT Summit 2024, Rijswijk](https://european-mct-summit-2024.sessionize.com/) agenda.

## Abstract

We'll dive deep in all Microsoft Teams Phone System functionality. Connecting your PBX to the PSTN using Direct Routing or a Calling Plan, building Auto Attendants, configuring devices and everything in between!
