# Windows 365: From zero to cloud in one hour!

**Speaker(s):** Jens Du Four — session on the [European MCT Summit 2024, Rijswijk](https://european-mct-summit-2024.sessionize.com/) agenda.

## Abstract

Are you curious about Windows 365? In this session, I will guide you through the entire process of setting up Windows 365 from scratch. You will learn everything you need to know to get started with the next step for Windows. Join me to discover the ease and convenience of Windows 365.
