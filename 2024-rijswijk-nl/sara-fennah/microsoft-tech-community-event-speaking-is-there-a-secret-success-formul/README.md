# Microsoft Tech Community event speaking, is there a secret success formula?

**Speaker(s):** Sara Fennah — session on the [European MCT Summit 2024, Rijswijk](https://european-mct-summit-2024.sessionize.com/) agenda.

## Abstract

Do you want to be a speaker at events? As a trainer you are already sharing your knowledge everyday and, probably, watching speakers at tech events, thinking "I can do that at least as well as them", but not sure where to get started getting a session selected or even what the whole process is.  

In this session established speakers will share best practice including
	• How to find events to apply to
	• How to craft session abstracts that get selected
	• Benefits of personal branding

You will leave this session armed with the not so secret formula to tech community speaking, and though we can't guarantee success in every event, the techniques have a proven track record helping new and existing speakers.

This is a non-technical, product agnostic session suitable for all.
