# CA Callahan

<img src="https://cdn.sessionize.com/image/14ee-400o400o1-BmSxvtTWmrCSYKKHj7K539.jpg" alt="CA Callahan" style="max-width:300px; max-height:300px; width:auto; height:auto;" />

Callahan has been a technical trainer since the mid-1990s, became an MCT in 1999, and is a SharePoint MVP Alumni. She has published books about administering SharePoint Foundation and Windows SharePoint Services, coauthored books about Windows Server 2003, 2003 R2, 2008, Windows Vista, SharePoint Server 2013, and associated Microsoft Courseware. She's spoken at events far and wide, from user groups and SharePoint Saturdays, to Ignite and Windows Connections. 

Right now she's exploring bold new worlds in the Immersive Learning space. Frequently advising companies on the best immersive platform for their needs, giving tours, writing onboarding and first touch instruction, as well as simply evangelizing and advocating for immersive collaboration, communication, and socialization. Gamifying or allowing user driven exploration has proven to increase confidence and ownership of the topic with less distraction than traditional, passive lecture/screenshare remote learning models. It is a natural next step to remote meeting that *does not* require a headset to enjoy the experience (she herself doesn't use a headset).
