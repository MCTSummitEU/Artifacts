# From zero to hero with Azure Arc-enabled Infrastructure in 50 minutes

**Speaker(s):** Wim Matthyssen — session on the [European MCT Summit 2024, Rijswijk](https://european-mct-summit-2024.sessionize.com/) agenda.

## Abstract

Azure Arc-enabled infrastructure is a part of the Azure Arc service that allows you to manage infrastructure from all your environments, including on-premises, other public clouds, and even edge devices, in a seamless way.

In this session, Wim and Micha will start by telling you all about how it can be used to easily provision, configure, update, monitor, and troubleshoot your existing infrastructure resources. Next to that, they will also explain how you can discover and manage resources in your VMware vSphere, System Center VMM, or Azure Stack HCI private cloud environment.

So, join us in this demo-packed session and learn some tips and tricks that can definitely help you optimize your infrastructure management processes with Azure Arc in only 50 minutes.
