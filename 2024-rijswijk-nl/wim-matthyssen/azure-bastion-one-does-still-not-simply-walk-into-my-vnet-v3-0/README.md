# Azure Bastion: One does (still) not simply walk into my VNet! v3.0

**Speaker(s):** Wim Matthyssen — session on the [European MCT Summit 2024, Rijswijk](https://european-mct-summit-2024.sessionize.com/) agenda.

## Abstract

Security is one of the most important things that a cloud administrator (IT administrator) should always keep in mind, especially when managing business-critical workloads in Azure. With Azure Bastion, you remain able to connect to your IaaS VMs in a secure and easy way, even from the native client on your local computer. I

In this session, you will not only discover how Bastion natively seamlessly integrates with the Azure Portal but also discover methods to enhance your VM access security through hardening and securing it with Network Security Groups (NSGs), Kerberos, and Just-in-Time (JIT) access. Next to that, you will learn how to automate its deployment and optimize cost savings by utilizing Bastion in combination with an Azure Logic App.

So, join me in this session to learn some best practices, tips, and tricks you should keep in mind when working with this "jumpbox-as-a-service".
