# The Purview Label Engine: Automatisierte Klassifizierung, Übersetzung und Dokumentation

**Speaker(s):** Michael Kirst-Neshva — session on the [MCT DACH Community Meetup](https://mctgermany.online/mct-community-meetup/) agenda.

## Abstract

PowerShell Live Demo: Globale Unternehmen stehen vor der Herausforderung, einheitliche Datenschutzstandards über Ländergrenzen und Sprachbarrieren hinweg zu implementieren. In diesem Vortrag präsentiere ich ein Framework, das Microsoft Purview-Labels wirklich skalierbar macht. Erfahre, wie Du die Logik von übergeordneten und untergeordneten Labels automatisch implementieren, Prioritäten mit einem Klick verwalten und für jede Geschäftseinheit sofort Compliance-Dokumente erstellen kannst.
